# Published AgentFarm manifests

A static directory of notarized runs. This is **not** a leaderboard,
score, or ranking — only experiment name, seed, CID, claim level, and date.
Anchoring is outsourced (OpenTimestamps / IPFS); this page is just an index.

`farm-notary index --registry PATH` rewrites this table and a
`registry.json` sidecar (`farmnotary.registry.v1`). How-to lives in the
[README](../README.md#campaigns-paper-pack-and-the-public-index); do not keep
prose below the table if this file is the live registry path.

```bash
farm-notary index --registry docs/registry.md --run-dir path/to/run
farm-notary index --registry docs/registry.md --campaign path/to/sweep
```
