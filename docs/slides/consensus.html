I · Setup  ·  what you may not take

A passing card is not a verified result.

  1. none This room uses the dry-run backend. No calendar, no pin, no gas. Not a failed experiment.
  2. L0 These bytes existed by time T; Bitcoin headers not verified by this tool. Dry-run cannot earn this. Pending OpenTimestamps is not L0 either.
  3. L1 Re-execution specified: command, git SHA, environment fingerprint. Not a completed re-run. The command was not run by verify.
  4. L2 Seed not grindable after the plan is anchored. Not scientific correctness. Not today’s demo.
  5. L3 A Sigstore keyless signature is on the reproduction receipt. Identity is recorded, not proven independent. Not independently reproduced.

II · Hash  ·  pre-specified design

Stamp the plan before the artifacts exist.

01 Plan farm-notary precommit --config run/run_config.json --command "python docs/demo/experiment.py --seed 0 --out '{run_dir}'"
02 Bind farm-notary manifest --run-dir run/ --profile consensus --precommit precommit.json --config run/run_config.json --command "python docs/demo/experiment.py --seed 0 --out '{run_dir}'"

This room is dry-run. A lab would pass --backend ots on the plan, then run. FarmNotary will still stamp a favorable run after the fact. It will not call that a pre-specified design.

III · Card  ·  the product

Reviewers read the card, not the exit code.

farm-notary verify --run-dir run/dry-run · this room
level: none — no earned ladder level
next:  L0 — these bytes existed by time T; Bitcoin headers not verified by this tool (missing: Bitcoin attestation)
•  tamper-evident record           — pass
•  existed by time T               — missing
•  pre-specified design            — precommit bound
•  bitwise reproducible (scoped)   — missing
•  not claimed: scientific correctness

Missing is not failure. Exit 0 means no attempted check failed — not that every claim was earned, and not that the science is right.

III · Card  ·  tamper

Change one official byte. The card breaks.

After a one-line edit

Append a comment to summary.csv. Rehash fails. tamper-evident record — fail. The zip on Drive would still open.

After restore

Put the bytes back. The card returns to pass. That is the value versus a laptop folder: the official record is checkable without asking the author.

Immutability is not correctness. A manifest can perfectly notarize a wrong winner.
